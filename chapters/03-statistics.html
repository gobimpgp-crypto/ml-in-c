Why Statistics?

Statistics shows up everywhere in ML:

  • Evaluating model performance (loss functions, accuracy)
  • Understanding your data (distributions, outliers)
  • Regularization relies on Gaussian priors
  • Batch normalization uses running mean and variance

Descriptive Statistics

Mean

μ = (1/n) × Σᵢ xᵢ
#include <stdio.h>
#include <math.h>

float mean(const float *x, int n) {
    float sum = 0.0f;
    for (int i = 0; i < n; i++)
        sum += x[i];
    return sum / n;
}

Variance and Standard Deviation

Variance measures spread. We use the sample variance (dividing by n−1, Bessel's correction):

σ² = (1/(n-1)) × Σᵢ (xᵢ - μ)²
// Sample variance (Bessel's correction: divide by n-1)
float variance(const float *x, int n) {
    float mu = mean(x, n);
    float sum_sq = 0.0f;
    for (int i = 0; i < n; i++) {
        float diff = x[i] - mu;
        sum_sq += diff * diff;
    }
    return sum_sq / (n - 1);
}

float std_dev(const float *x, int n) {
    return sqrtf(variance(x, n));
}

int main(void) {
    float data[] = {2.0f, 4.0f, 4.0f, 4.0f, 5.0f, 5.0f, 7.0f, 9.0f};
    int n = 8;

    printf("Mean:     %.4f\n", mean(data, n));     // 5.0000
    printf("Variance: %.4f\n", variance(data, n)); // 4.5714
    printf("Std Dev:  %.4f\n", std_dev(data, n));  // 2.1381
    return 0;
}

Min, Max, Range

float arr_min(const float *x, int n) {
    float m = x[0];
    for (int i = 1; i < n; i++) if (x[i] < m) m = x[i];
    return m;
}

float arr_max(const float *x, int n) {
    float m = x[0];
    for (int i = 1; i < n; i++) if (x[i] > m) m = x[i];
    return m;
}

Data Normalization

Before feeding data to ML models, normalize it. Two common methods:

Min-Max Normalization (scales to [0, 1])

x' = (x - min) / (max - min)
void normalize_minmax(float *x, int n) {
    float mn = arr_min(x, n);
    float mx = arr_max(x, n);
    float range = mx - mn;
    for (int i = 0; i < n; i++)
        x[i] = (x[i] - mn) / range;
}

Z-Score Standardization (zero mean, unit variance)

x' = (x - μ) / σ
void standardize(float *x, int n) {
    float mu  = mean(x, n);
    float sig = std_dev(x, n);
    for (int i = 0; i < n; i++)
        x[i] = (x[i] - mu) / sig;
}

// After standardize: mean ≈ 0, std_dev ≈ 1
When to use which? Use z-score (standardize) for gradient-based algorithms like linear regression and neural networks — it keeps gradients well-behaved. Use min-max for algorithms sensitive to feature ranges (e.g., k-NN).

Covariance and Correlation

Covariance measures how two variables move together:

Cov(X,Y) = (1/(n-1)) × Σᵢ (xᵢ - μₓ)(yᵢ - μᵧ)
float covariance(const float *x, const float *y, int n) {
    float mu_x = mean(x, n);
    float mu_y = mean(y, n);
    float sum = 0.0f;
    for (int i = 0; i < n; i++)
        sum += (x[i] - mu_x) * (y[i] - mu_y);
    return sum / (n - 1);
}

// Pearson correlation: normalized covariance [-1, 1]
float correlation(const float *x, const float *y, int n) {
    return covariance(x, y, n) / (std_dev(x, n) * std_dev(y, n));
}

Loss Functions

Loss functions are statistical measures of how wrong our model is. We'll use these in every subsequent chapter.

Mean Squared Error (MSE)

MSE = (1/n) × Σᵢ (yᵢ - ŷᵢ)²
// y_true: ground truth labels
// y_pred: model predictions
float mse(const float *y_true, const float *y_pred, int n) {
    float sum = 0.0f;
    for (int i = 0; i < n; i++) {
        float diff = y_true[i] - y_pred[i];
        sum += diff * diff;
    }
    return sum / n;
}

Mean Absolute Error (MAE)

MAE = (1/n) × Σᵢ |yᵢ - ŷᵢ|
float mae(const float *y_true, const float *y_pred, int n) {
    float sum = 0.0f;
    for (int i = 0; i < n; i++)
        sum += fabsf(y_true[i] - y_pred[i]);
    return sum / n;
}

Binary Cross-Entropy

Used for binary classification (output is probability between 0 and 1):

BCE = -(1/n) × Σᵢ [yᵢ log(ŷᵢ) + (1-yᵢ) log(1-ŷᵢ)]
#define EPSILON 1e-7f  // avoid log(0)

float binary_cross_entropy(const float *y_true, const float *y_pred, int n) {
    float sum = 0.0f;
    for (int i = 0; i < n; i++) {
        float p = y_pred[i];
        // Clip to avoid log(0)
        if (p < EPSILON)  p = EPSILON;
        if (p > 1.0f - EPSILON) p = 1.0f - EPSILON;
        sum += y_true[i] * logf(p) + (1.0f - y_true[i]) * logf(1.0f - p);
    }
    return -sum / n;
}

Random Number Generation

ML needs random numbers for weight initialization. C's rand() is poor quality — let's use a better alternative:

#include <stdlib.h>
#include <time.h>

// Box-Muller transform: uniform → Gaussian N(0,1)
float rand_gaussian(void) {
    float u1 = ((float)rand() + 1.0f) / ((float)RAND_MAX + 2.0f);
    float u2 = ((float)rand() + 1.0f) / ((float)RAND_MAX + 2.0f);
    return sqrtf(-2.0f * logf(u1)) * cosf(2.0f * 3.14159265f * u2);
}

// Initialize an array with N(0, std) random values
void rand_init(float *arr, int n, float std) {
    srand((unsigned)time(NULL));
    for (int i = 0; i < n; i++)
        arr[i] = rand_gaussian() * std;
}

// Example: He initialization for ReLU layers
// std = sqrt(2.0 / fan_in)
void he_init(float *weights, int fan_in, int n) {
    float std = sqrtf(2.0f / fan_in);
    rand_init(weights, n, std);
}
✓ Why He Initialization? Random weights with the right scale prevent vanishing/exploding gradients at the start of training. He init (std = √(2/fan_in)) is optimal for ReLU activations.

Summary

  • Mean, variance, and std dev describe the shape of your data
  • Normalize with z-score before feeding data to gradient-based ML
  • Covariance and correlation reveal relationships between features
  • MSE for regression, Binary Cross-Entropy for classification
  • Use Box-Muller for proper Gaussian random initialization
