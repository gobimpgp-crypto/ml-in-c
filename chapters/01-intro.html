What is Machine Learning?

Machine learning is the science of making computers learn from data without being explicitly programmed for every case. Instead of writing rules by hand, we give an algorithm data and let it discover the rules itself.

Three main paradigms:

  • Supervised learning — learn from labeled examples (spam vs. not spam)
  • Unsupervised learning — find structure in unlabeled data (clustering)
  • Reinforcement learning — learn by trial and reward/penalty

This course focuses on supervised learning — it's the foundation for most real-world ML systems.

Why Learn ML in C?

Most ML tutorials use Python. That's fine for getting results fast, but it hides everything interesting. When you implement backpropagation yourself in C, you will understand it for life. The benefits:

  • You see exactly how gradients flow through a network
  • You develop an intuition for memory layout and numerical stability
  • Production ML engines (TensorFlow XLA, ggml, llama.cpp) are written in C/C++
  • No import sklearn crutch — every parameter is yours
Prerequisites You need basic C knowledge: variables, loops, functions, pointers, and structs. If you're new to C, spend a day with the K&R book first.

Setting Up Your Environment

Install GCC

On Linux/macOS you likely already have GCC. On Windows, install MinGW or WSL.

# Check GCC is installed
gcc --version

# Compile a C file
gcc -o program program.c -lm

# With optimizations
gcc -O2 -o program program.c -lm

The -lm flag links the math library — you'll need it for expf(), sqrtf(), etc.

Your First ML-ish C Program

Let's write the simplest possible ML: predicting a value with a linear function y = w * x + b.

#include <stdio.h>

// A linear model: y = weight * x + bias
float predict(float x, float weight, float bias) {
    return weight * x + bias;
}

int main(void) {
    // Pretend we learned these parameters from data
    float weight = 2.5f;
    float bias   = 1.0f;

    // Predict for several inputs
    float inputs[] = {1.0f, 2.0f, 3.0f, 4.0f};
    int n = 4;

    printf("%-10s %-10s\n", "Input", "Prediction");
    for (int i = 0; i < n; i++) {
        float pred = predict(inputs[i], weight, bias);
        printf("%-10.1f %-10.2f\n", inputs[i], pred);
    }
    return 0;
}

Compile and run:

gcc -o first_ml first_ml.c && ./first_ml

Output:

Input      Prediction
1.0        3.50
2.0        6.00
3.0        8.50
4.0        11.00

C Memory Model — A Quick Refresher

ML in C lives or dies by your pointer skills. A brief refresher:

#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n = 5;

    // Stack allocation — fast, auto-freed
    float stack_arr[5] = {1.0f, 2.0f, 3.0f, 4.0f, 5.0f};

    // Heap allocation — manual management, any size
    float *heap_arr = malloc(n * sizeof(float));
    if (!heap_arr) { perror("malloc"); return 1; }

    for (int i = 0; i < n; i++)
        heap_arr[i] = (float)(i + 1);

    // Always free heap memory
    free(heap_arr);
    return 0;
}
⚠ Memory Rule Every malloc() must have a matching free(). Neural network weights are heap-allocated — forget to free them and you have a leak.

Floating Point in C

ML uses floating point math constantly. Use float (32-bit) for most ML work — it's faster and uses half the memory of double.

#include <stdio.h>
#include <math.h>   // for expf, sqrtf, fabsf, etc.

int main(void) {
    float a = 0.1f + 0.2f;
    printf("0.1 + 0.2 = %.17f\n", (double)a);
    // Output: 0.30000001192092896
    // Floating point is NOT exact!

    // Common ML math functions
    float x = 2.0f;
    printf("exp(2)  = %f\n", expf(x));
    printf("sqrt(2) = %f\n", sqrtf(x));
    printf("log(2)  = %f\n", logf(x));
    printf("|−3.5|  = %f\n", fabsf(-3.5f));
    return 0;
}
✓ Key Takeaway Floating point arithmetic is approximate. In ML this is fine — your gradients don't need 15 decimal places. But always use float suffix (1.0f, not 1.0) to avoid implicit double promotion.

Structs for ML Data Structures

You'll use struct to represent datasets, layers, and models throughout this course:

#include <stdlib.h>
#include <string.h>

// A simple dataset
typedef struct {
    float *X;      // input features, shape [n_samples × n_features]
    float *y;      // labels, shape [n_samples]
    int    n;      // number of samples
    int    features;
} Dataset;

Dataset *dataset_create(int n, int features) {
    Dataset *ds = malloc(sizeof(Dataset));
    ds->X = malloc(n * features * sizeof(float));
    ds->y = malloc(n * sizeof(float));
    ds->n = n;
    ds->features = features;
    return ds;
}

void dataset_free(Dataset *ds) {
    free(ds->X);
    free(ds->y);
    free(ds);
}

Summary

  • ML = learning patterns from data instead of hand-coding rules
  • C gives you full visibility into the math and memory of ML algorithms
  • Use gcc -O2 -lm to compile ML programs
  • Prefer float over double for ML; always free heap memory
  • Use struct and typedef to build clean ML data structures
